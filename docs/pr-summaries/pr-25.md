## Description
## What

`email_sent` stops being *the* delivery contract. The `digests` row now carries one flag per channel — `email_sent`, `site_published`, `telegram_sent` — each marked in its own commit the moment that channel succeeds, each retried independently by later runs. Channels degrade independently: a broken SMTP path can't block a healthy site publish, and a retry never duplicates a channel that already succeeded.

- **Site channel**: `publish_to_site` PUTs the digest (pre-rendered, nh3-sanitized HTML from the email's own pipeline via the new `emailer.render_body_html`, plus structured tldr/section/attention fields) to the news-site Worker's `/ingest/<id>` with `x-ingest-key` (Worker: Dezoxy/toom-edge#63, already deployed and live-tested).
- **Telegram channel**: `send_telegram_tldr` posts the TL;DR + site link to the group topic. Plain text deliberately — Telegram's markdown parse modes reject a whole message on one unescaped character of model text; plain text cannot fail to parse. `message_thread_id` only when non-zero. Error paths never carry the bot-token-bearing URL or a response body.
- **`EMAIL_ENABLED`**: default true; when false the flag is ignored for pendingness/retry, so legacy `email_sent=0` rows don't become eternally pending.
- **Ordering contract**: site before Telegram; if site is enabled but unpublished this run, Telegram is skipped (never link to a page that isn't there) and retried next run. Site-disabled deployments don't block Telegram.
- **Archive decoupled**: `archive()` runs once, unconditionally, right after `create_digest` — the old email-gated archiving would never archive anything under `EMAIL_ENABLED=false`.

## Review changes on the draft

- Poison-pill fix: the Worker's validator 400s an empty `tldr`, and `extract_tldr` can legitimately return `""` on a pathological body — that digest would have failed site publish on every retry forever. Now falls back to `"(no summary)"`.

## Config

New: `EMAIL_ENABLED`, `SITE_PUBLISH_URL` (+required `SITE_INGEST_KEY`), `SITE_PUBLIC_BASE` (secret — embeds the capability token), `TELEGRAM_NOTIFY_BOT_TOKEN`/`_CHAT_ID`/`_THREAD_ID`. Startup guard: at least one channel must be enabled. All new secrets `repr=False`.
