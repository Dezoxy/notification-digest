## What

The summarizer received `[score N, M comments]` and was told to treat the pair as a single salience input. So a post with **600 comments on 2,400 upvotes** (an argument) read identically to one with **50 comments on 2,400** (broad agreement) — different stories about the same community, collapsed into one number.

Upvotes measure how many agreed; comments measure how much was argued. The prompt now says so, and draws the editorial consequence:

- A comment count running high against the score — roughly one per four upvotes or more, against one per ten as ordinary — marks a **divided** community, and the passage must report it as divided rather than promoting the top-voted view to settled consensus.
- A high score with few comments is the inverse: broad, untroubled agreement.
- Never report a contentious thread as though the community spoke with one voice.

Real example from the live verification run on r/hungary: the top post was 2,429 upvotes with 605 comments — a 1:4 ratio, i.e. a genuine argument, not a community nodding along. Under the old wording that nuance was invisible.

## On the thresholds

The ratio anchors are deliberately fuzzy ("roughly", "ordinary") rather than exact. The baseline genuinely varies by community — news subs argue more than link-sharing subs — so this is calibration for the model's judgment, not a threshold to compute against.
