## Description
## What
The digest page's colophon (the **Sources** row plus the **Written by** / **Translated with** rows) is now collapsed by default behind one tap target:

```
▸ HOW THIS WAS MADE        (HU: HOGYAN KÉSZÜLT)
```

This applies to every digest page (daily, weekly, synthesis, all through `renderDigestPage`) in both languages.

## How
- `render-digest.js`: `<div class="colophon">` becomes `<details class="colophon"><summary>…</summary><div class="colophonbody">…</div></details>`. It's a native disclosure with **no JS**, matching the `.arccontext` primer.
- `strings.js`: new `colophonLabel` for EN/HU.
- `css.js`: summary styling copied from `.arccontext summary` (mono, muted, accent on hover/focus, focus ring). The `.sourcekey` margin reset moved to `.colophonbody >`.
- **Print:** the existing print rule says the colophon rows "stay visible in print", so print sets `::details-content` to visible and hides the summary. A browser without `::details-content` prints it collapsed, the same as the screen.

## Also: hide the closing coverage line
`From 12 items; 5 informed this briefing, while 4 were chatter.` and the daily/weekly `Synthesized from N briefings covering M items.` are hidden on the site by owner decision, because the source key already carries those numbers per source.
- `.digest p.foot { display: none; }`. The `.closing` rule (the About-page caveat) is split out and keeps its styling.
- **Why CSS and not the prompts:** one rule covers every archived digest, and the model's output contract (`prompts/digest|daily|weekly.md`, plus `verify-daily.md`, which preserves the line) stays untouched. Email is disabled on the VM, so the line has no other reader.
- New assertion in `render.test.mjs`. Checked in a browser: `p.foot` computes to `display: none`, and the last section now runs straight into the colophon.
