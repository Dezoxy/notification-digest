# PR #60: fix: exclude the window and weekly second-tier rubrics from story arcs
[View PR](https://github.com/Dezoxy/notification-digest/pull/60) · @Dezoxy · merged 2026-08-10 · `ae76934` · `fix/structural-rubric-headings-window-week -> main` · +114/-15 across 2 files

## Description
Owner-reported: the site renders a live **`ALSO THIS WINDOW ×5 THIS WEEK`** story-arc chip.

`## Also this window` is `prompts/digest.md`'s fixed second-tier section — mandated by the prompt, not chosen by the model — so it appears in essentially every window digest. Feeding it to the site's "×N this week" recurrence counter manufactures a permanent false arc.

## Why #58 missed it

PR #58 established this exclusion but audited only `daily.md` and `weekly.md` — the prompts behind the headings the owner had happened to see. Auditing all three briefing prompts:

| Prompt | Mandated fixed headings | Was excluded? |
|---|---|---|
| `digest.md` (window, every 3h) | `## Hungary`, **`## Also this window`** | Hungary ✓ · **✗** |
| `daily.md` | `## Hungary`, `## Also today` | ✓ ✓ |
| `weekly.md` | `## Hungary`, **`## Also this week`**, `## Watching next week` | ✓ **✗** ✓ |

Two omissions. The window one is the worst: window digests run every 3 hours, so the false arc reaches ×5 within a day. `Also this week` is the same class on a slower burn.

## The actual fix is the guard

Adding two strings fixes today. The maintenance-coupling comment in `publish.py` has now been missed twice by hand, so the real change is two tests that **read the prompt files** rather than restating them:

- **`cover_every_prompt_mandated_heading`** — extracts `` `## X` `` references appearing inside a **bold run**. The prompts state every mandated section that way (``- **`## Also today`** takes...``, ``- **Standing rule — `## Hungary`:**``), while example story headings (`## Missile strike in Poland`) only ever appear in plain prose. Verified to yield exactly the five mandated headings and zero example-heading false positives across all four prompt files. Carries a `>= 5` floor so a prompt-format change can't make it pass vacuously.
- **`has_no_stale_entries`** — the reverse direction, so an entry no prompt mandates can't silently suppress a real story heading that happens to match it.

Both were confirmed to **fail** when the invariant is broken (removed `also this window`; added a bogus entry), not merely to pass as written.

## Already-published digests

This stops new topic rows only. The site counts arcs over a trailing 7-day window, so the existing false chips age out on their own within a week — no D1 backfill needed.

Note this ships nothing until a tag is cut and the homelab repo bumps the pin.
