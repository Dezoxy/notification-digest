## What

Flag-gated `reddit` source: one `client_credentials` token per run, then `GET /r/{sub}/top?t=day` per configured subreddit (`REDDIT_SUBREDDITS`, validated), with Reddit's mandated descriptive User-Agent. Built after live verification that unauthenticated RSS/JSON is per-IP throttled into uselessness (4/5 requests 429 from the production IP, paced).

- **Failure semantics**: token failure fails the run; per-sub failures tolerated rss.py-style (failed only if *all* fail).
- **Idempotency**: no cursor (t=day is a rolling ranked window) — `UNIQUE(source, source_id)` + defensive 24h `created_utc` re-check. Stickied/NSFW skipped.
- **Salience**: `[score N, M comments]` rides in item text; the prompt weights by community signal.
- **Migration**: `items.source` CHECK widened to five values via the established rebuild pattern.

## Prompt

- Reddit items treated as News (cluster/merge/interest filter), scores as salience input.
- Interest filter widened: major world events of international consequence from general-news subs (r/news etc.) are in scope; the noise bar (local crime, celebrity, product marketing) explicitly unchanged.
- **Standing `## Hungary` rule** (owner request): guaranteed compact section whenever `chat_title == "r/hungary"` items exist — exempt from the section budget and Also-fold; mirrored into `prompts/daily.md` so the evening brief can't consolidate it away (review addition — the daily's arc-synthesis would otherwise drop it).
