## Description
Prep for Cloudflare Workers Builds, which builds from a clean checkout with no local state.

**wrangler was never a dependency** — every deploy so far used `npx wrangler`, which downloads whatever is newest. Fine at a keyboard where a surprise is visible; wrong in CI, where it means the version that deploys is whatever shipped that morning. Pinned to **4.101.0**, the exact version used for every deploy this session.

Not hypothetical for this Worker: wrangler and workerd already disagreed here once — `wrangler dev` refused to start because its bundled runtime predated `wrangler.jsonc`'s `compatibility_date`. A floating version turns that class of mismatch into a deploy-time failure.

Also adds `npm run deploy` / `npm run deploy:preview`, so the two commands the build settings need have names in the repo rather than living only in a dashboard field.

**Verified in a clean clone** (what the build environment actually does): `npm ci && npm test` exits 0, and `wrangler deploy --dry-run` bundles.
