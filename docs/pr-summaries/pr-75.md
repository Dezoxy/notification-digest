## Description
## Why

The digest had become one-directional: over the last 57 window digests, one Telegram channel pair (ASI_Alliance + fetchunofficial) held a section in 72% of briefings, 57% of all sections re-trod already-covered arcs, and news feeds contributed under 5% of citations. Three root causes, all fixed here.

## Changes

**1. Source-balanced item selection** (`allocate_by_source`, summarize.py)
- The old `get_unsummarized_items(limit=200)` applied the cap before any notion of source balance; collectors stamp one `fetched_at` per batch and Telegram runs first, so a backlog burst filled entire windows with one source (live incident: 2026-08-13T07:20Z produced a briefing from 200 telegram items, 0 everything else; the next three runs were nearly as skewed).
- Now: 1000-item candidate pool → per-lane quotas (news 60 / telegram 55 / x 55 / reddit 40 / positions 30 / polymarket 10 = 250). Unfilled quota redistributes round-robin; oldest-first within lanes preserves the backlog-drain contract; output is a filter of the input so the summarized set and stamped set stay identical.
- New reserved **positions** lane: items from `POSITIONS_TG_CHANNELS` (new env, matched on t.me URL prefix) get a hard-capped 30 slots — guaranteed presence, barred from crowding. Feeds the new standing `## Positions` section (owner's investment channels).
- New `allocation` log line (counts only) for Loki visibility of lane pressure.

**2. Arc-key cap ordering bug** (state.py)
- `get_recent_arc_keys` ordered `ak.key ASC LIMIT 50`; the live 7-day window has 135 distinct keys, so the alphabetical cut silently dropped every key from "h" onward — including `hormuz` (29 appearances) and `ukraine-strikes` (22) — causing exactly the key fragmentation the feature exists to prevent (six coexisting `qwen-*` keys, five `openai-*`).
- Now ordered by appearance count DESC; counts returned and rendered into `{{RECENT_ARCS}}` (`- hormuz (covered in 29 briefings)`) as the model's over-coverage signal.

**3. Prompt editorial rework** (prompts/digest.md)
- Standing `## Positions` section: holder-framed, exempt from section budget / Also-fold / delta compression, no arc key, placed before `## Hungary`. `format_recent_coverage` skips it (and `## Hungary`) so standing sections can't self-suppress.
- Delta/heading contradiction resolved: a delta-only update now goes in `## Also this window`, not under its own heading — recurring arcs stop squatting the section budget; the "genuinely bigger" escape hatch stays.
- Hungary rule widened: `r/hungary` OR news items on telex.hu/portfolio.hu (new feeds land in the homelab PR).
- Budgets rescaled for the 6h cadence: ~10 sections, Also-window 250–300 words, 2,800-word ceiling, `_MAX_ITEMS_PER_DIGEST` 200→250.
- General-news feeds (BBC/AJ/AP/POLITICO/FT) explicitly held to the existing interest bar.
