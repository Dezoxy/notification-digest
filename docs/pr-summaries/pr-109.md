## Description
`workers/news-site/.gitignore` already ignores `.wrangler/` — but wrangler drops that directory **wherever it is invoked**, not where its config lives.

Not hypothetical — it happened during the 2026-08-27 site-publish work (`wrangler d1 execute` from the repo root after a directory change) and was cleaned up by hand. One line prevents the next one.
