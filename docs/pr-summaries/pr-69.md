## Description
The owner ended the design's premise: members don't react or reply on the
digest's Telegram posts, they just open the site. The design sampled
reactions and replies, so it would have collected zeros and rendered them
as apathy for stories people are demonstrably reading — worse than not
shipping it, since any ranking term fed from that would actively mislead.

Rejected rather than parked: implementation quality can't fix a signal
that isn't there. The entry's design is kept in full as the record. What
is NOT rejected is the underlying question — the real signal, if anywhere,
is site-side (opens, follows), but that means introducing per-reader
tracking this product has deliberately avoided, and nobody has asked for
that trade. It would start as a fresh entry, not a revival.
