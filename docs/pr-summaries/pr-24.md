## Description
## What

New flag-gated collector (`source: polymarket`): each run fetches the top-30 active markets by **24h volume** from the Polymarket Gamma API and emits an Item for every binary market whose probability moved ≥ `POLYMARKET_SWING_THRESHOLD` (default 15pp) against its stored anchor. Money-weighted odds as a salience signal — a big overnight swing usually means something happened.

**The anchor rule:** the stored per-market probability is the last *reported* one, not the last observed. Below-threshold moves never advance it, so slow drift accumulates across runs until it crosses the threshold and is reported once with full magnitude. First sightings record a baseline silently.

## Live-verified corrections (each found by testing the real API before/while writing code)

- **`volume24hr` ordering, not `volumeNum`** — lifetime volume ranks stale mega-markets ("Will Jesus Christ return before 2027?") on top; 24h volume is money moving *now*.
- **Sports/esports excluded at the collector** — the 24h ranking is dominated by live tennis/Dota markets whose in-game odds swing constantly; discriminator is the `sportsMarketType` key (present on sports, absent on real-world markets), with a fixed 100-market overfetch so `top_n` counts post-filter survivors.
- **Custom User-Agent required** — Cloudflare's Browser Integrity Check rejects `Python-urllib/3.x` with error 1010 before the request reaches the Worker; `notification-digest/1.0` passes.
- **`outcomes`/`outcomePrices` are JSON-encoded strings** (double-decode), confirmed live.

## Network context

polymarket.com (incl. `gamma-api`) is ISP-blocked in Hungary. In production `POLYMARKET_API_BASE` points at an authenticated Cloudflare Worker proxy (deployed from cloudflare-terraform: hardcoded upstream, GET `/markets` only, timing-safe `x-proxy-key` check). The key is `POLYMARKET_PROXY_KEY` — `field(repr=False)`, never logged.

## State / migration

- New `polymarket_probs` table: `probability` = last reported (the anchor), `updated_at` = last observed (drives a 30-day prune of resolved/delisted markets).

- Anchor upserts ride inside `commit_new_items`' transaction: a failed item insert rolls back the anchor move.
