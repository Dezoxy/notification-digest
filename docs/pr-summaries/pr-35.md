## Description
## What

Reddit's Data Team formally refused the owner's API access application (email 2026-08-06), so the OAuth app-only collector from PR #32 can never obtain working credentials. This PR swaps its auth layer for the owner's own logged-in **`reddit_session` browser cookie**, sent as a Cookie header to `old.reddit.com`'s `.json` endpoints — the same ToS-risk posture the repo already takes for X via twikit (cookie session, unofficial, owner accepts the risk).

- **`_verify_session`** (GET `/api/me.json`) replaces the token fetch with identical whole-run failure semantics: any failure → `failed=True`, zero further network calls. A logged-in session returns `data.name`; an anonymous/dead cookie returns `{}` → `ValueError`.
- **Auth back-off mid-run** (the `X_ENABLED`-style hard rule): a 401/403 on a per-subreddit request after a successful verify means the session died during the run — one warning, `failed=True`, `break`. Never keeps hammering a dead credential; the next scheduled run (3h) is the retry. Non-auth errors (incl. 429) keep the existing per-subreddit fault tolerance.
- **`old.reddit.com`, deliberately**: it's the surface that accepts a bare `reddit_session` cookie; modern `www.reddit.com` wants a short-lived `token_v2` JWT a static export can't provide.
- **Config**: `REDDIT_SESSION_COOKIE` (secret, `repr=False`, required when `REDDIT_ENABLED=true`) replaces `REDDIT_CLIENT_ID`/`REDDIT_CLIENT_SECRET`. Cookie value is sent verbatim (never re-encoded), never logged — tests assert it's absent from log output on every failure path.
- **Pacing** bumped 0.5s → 2s between subreddits: logged-in old.reddit limits are undocumented, and this collector must err polite given the account-risk posture.
- **`rss.py` untouched**: the RSS reddit feeds stay configured (homelab side) as the safety net until cookie auth is live-verified from the production VM's IP — dropping them is a homelab config change after a proven run, not part of this PR.

## Not yet live-verified

Anonymous `.json` is a hard 403 (re-confirmed today); whether the cookie flips that to 200 from the VM's IP — and whether old.reddit prefers a browser-like UA for cookie sessions — needs a real run with the owner's cookie. The module docstring flags both.
