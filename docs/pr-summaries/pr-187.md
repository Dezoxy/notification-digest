## Description
Notification-digest currently depends on the shared homelab VM for scheduling, exclusive session ownership, SQLite persistence and deployment. This change prepares nine app-owned Azure Container Apps Jobs with durable Blob-backed SQLite snapshots, while preserving the existing Claude CLI subscription, current model/prompt configuration and delivery modes.

Jobs default to Manual mode. No production resources, credentials, schedules or VM flags were changed. Recovery remains in Azure; there is no VM return procedure. The baseline image pin records 0.28.0 and must be replaced by the tested migration release before executing jobs. The migration intentionally retains the measured VM CLI 2.1.284; the independently merged 2.1.293 update is deferred until pilot validation. Other current-main updates are preserved.

The runner serializes modes with a renewable lease and conditional manifest writes, checkpoints committed progress around external effects, rejects missing/corrupt state, deduplicates schedule slots and handles Budapest DST. Unknown Telegram/email outcomes suspend automatic resend until explicit reconciliation. Process fencing is verified for container PID 1. Private state exports preserve SQLite, seed/live X cookies and archive lineage; daily backup references and garbage collection bound history.

Azure infrastructure includes per-secret Key Vault references, managed identity, private GHCR credentials, EU storage/logging, aggregate alerts and a budget notification. Deployment uses OIDC, remote HCP Terraform state and an approved saved plan. Shared-alert preparation in the homelab repository is a separate prerequisite. Live identity/egress/log-schema/restore/cost checks remain pilot gates; checkpoint cost is unmeasured.
