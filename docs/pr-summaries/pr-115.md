# PR #115: feat(news-site): flow daily/weekly cards two-across, drop their day headers

## Description
Owner request: make the daily and weekly index views use the two-column grid the All view has.

## Flipping the column count alone would have re-created the original bug

Those views yield **one card per day-group** — one brief a day, one a week — and every day header spans both columns (`grid-column: 1 / -1`), forcing a new row:

```
┌──────────────────────────────────┐
│ MONDAY, 24 AUGUST 2026           │  <- spans both
├────────────────┬─────────────────┤
│ 20:43 · 757    │   (empty)       │  <- half width
├────────────────┴─────────────────┤
│ SUNDAY, 23 AUGUST 2026           │
├────────────────┬─────────────────┤
│ 20:43 · 613    │   (empty)       │
└────────────────┴─────────────────┘
```

That's the owner-reported *"the text has just half the width"*, previously answered by dropping these views to one column via `data-ledger="single"`.

**The column count was never the cause. The day headers were.** This drops them on daily/weekly instead, so cards flow two-across and fill the grid. The All view keeps its headers — ~8 window digests a day makes them a real divider.

The date those headers carried moves **into the card**: `Mon 24 Aug · 20:43` instead of a bare `20:43`, reusing `formatShortDate`. The All view keeps time only; repeating the date on each of a day's eight digests would be noise.

## Changes

- **`src/render-index.js`** — `renderLedgerFor` (new, exported) decides grouped vs flat; `renderIndexEntry` prefixes the short date off-All; `ledgerAttr` removed.
- **`src/css.js`** — `section[data-ledger="single"]` retired, with its reasoning **rewritten rather than deleted**. The next reader needs to know why two columns were once wrong here, or they'll "fix" it back.

## The goldens cannot review this — stated plainly

The fixture set has **one** daily and **one** weekly digest, each of which becomes its view's lead card. So `daily-en`/`weekly-en` contain **zero ledger entries and zero day headers**, and their diff shows only the dropped attribute:

```
daily-en    dayheads=0  entries=0
weekly-en   dayheads=0  entries=0
index-en    dayheads=2  entries=2
```

`renderLedgerFor` is therefore asserted **directly** in `render.test.mjs` — All view: one `.dayhead` per day; daily/weekly: none, every row preserved. Richer fixtures would demonstrate it properly but would perturb every existing golden, so that's deliberately not in this change.

Committed in **two commits** so the golden diff is still a review artifact: `be8b25f` adds daily/weekly goldens at the *old* layout, `0bdf84f` is the change. Every golden did move — `css.js` comments ship inlined in each page.
