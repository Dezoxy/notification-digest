# PR #156: docs(architecture): make the Documentation tab and the PDF the same document
[View PR](https://github.com/Dezoxy/notification-digest/pull/156) · @Dezoxy · merged 2026-09-20 · `691e780` · `docs/architecture-tab-equals-pdf -> main` · +1107/-183 across 32 files

## Description
Structurizr imports `docs/architecture/overview/` and nothing else. The PDF was
that **plus** the nine documents listed in `pdf-sections.txt`. The two
renderings described the same system differently.

## Why homelab and hopin don't have this gap

Not tooling — `build_architecture_pdf_source.py` is **byte-identical** in all
three repos. The difference is where the weight sits:

| | Tab content | PDF extras | PDF length comes from |
|---|---|---|---|
| homelab | ~339 lines, 5 files | none | **the tab** |
| hopin | ~449 lines, 7 files | 2 registers | **the tab** |
| before | **130 lines**, 3 files | **9 registers** | **the appendix** |
| after | **~510 lines**, 7 files | none | **the tab** |

Their reading paths *are* the substance — they embed views at each stop and
link out to detail. Ours was a five-row table in `README.md` that Structurizr
never sees.

## What changed

`overview/` is now the whole architecture description, in seven ordered files.
`01` carries the single `#`; `02`–`07` are `##` sections, ordered by their
numeric prefix:

| | Section | Stops |
|---|---|---|
| 01 | Notification Digest — context, building blocks, one run | — |
| 02 | Scope | — |
| 03 | Reviewing the design | 5 |
| 04 | Operating it | 5 |
| 05 | Assessing exposure | 4 |
| 06 | Changing it | 5 |
| 07 | Glossary | — |

`pdf-sections.txt` is now empty, with a comment explaining that a line in it is
a page the PDF has and the tab does not.

**The registers do not move.** `requirements/`, `security/`, `data/`, `risks/`
and the rest remain the single source of truth for every cited ID; `ID_OWNERS`
is untouched. The reading paths cite and link — they never copy a register's
table.

## A new check, because this introduced a blind spot

Files in `overview/` must link out by **absolute** URL: a relative link does
not resolve inside a rendered Documentation tab (this is also what homelab and
hopin do). But `check_links()` skips `http(s)`, so 20+ links in the
most-read documents would have gone unverified.

`check_self_links()` turns this repo's own `blob/main/...` URLs back into paths
and resolves them on disk. It strips inline code first, so writing the
convention down in `CLAUDE.md` does not fail the check that enforces it.
