## Description
The dashboard had drifted from `wrangler.jsonc`: the UI carries the expanded observability shape with **logs and traces enabled**, while the file still had the two-line legacy form.

**The file wins on every deploy** — so the dashboard's traces toggle would have been reverted by the next one, and now that deploys run automatically on every push to `main`, that would have happened silently with nothing to point at. Declaring the full shape here makes the file the single source of truth, which is the only arrangement that survives automated deploys.

## Why traces, on this Worker

They split an invocation into spans, so D1 query cost is visible separately from render cost. The perf pass here was tuned against a five-row fixture — this is the only way to see what a *real* index render costs.

## The tradeoff, documented next to the trust model

Both logs and traces record request URLs, and this site's credential **is** the URL path — so the capability token comes to rest in retained observability data. `redact_query_string` doesn't help; the token isn't in the query string.

Accepted knowingly (one operator, real debugging value), with `head_sampling_rate` named as the lever if that ever stops being true. Worth stating plainly, because every other part of this design works hard to keep that token out of referrers, caches and crawlers — this is the one place it deliberately comes to rest.

`persist` and `redact_query_string` left undeclared: they're the defaults, and fewer declared knobs means fewer things that can drift.
