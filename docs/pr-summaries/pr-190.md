## Why

The foundation apply (`jobs_enabled=false`) created 16 of 17 resources and then failed on `notification-digest-failures`:

```
400 BadRequest: union: must have at least one operand that can be evaluated
successfully when running with 'Fuzzy' mode (SEM0529)
```
