## Description
## Problem

Digests 20 and 60 failed `translate_digest` with `SummarizeError` within ~5s on every attempt (2026-08-06), while 60+ sibling rows translated fine.

**Root cause** (reproduced manually in the production container): `TRANSLATE_MODEL=sonnet` resolves to Sonnet 5, whose real-time cyber safeguards deterministically flag the security-heavy 2026-08-01 digest content. The `claude` CLI (2.1.220) prints `API Error: Sonnet 5's safeguards flagged this message…` to **stdout** (stderr empty) and exits 1 in ~4s. `run_claude`'s error ("stderr suppressed, 0 chars") masked this — API errors land on stdout. Prompt length was ruled out (larger digests translated fine); the refusal is content-triggered and deterministic, so all retries failed identically. The same prompts translate fine on `claude-sonnet-4-6`, which predates those classifiers.

## Changes

- **summarize.py** — classify the content-free refusal marker (`API Error:` head + `safeguards flagged`) on non-zero exit into a new `SafeguardsRefusalError` (subclass of `SummarizeError`); the generic non-zero-exit message now reports both stream lengths.
- **translate.py** — `translate_digest` gains `fallback_model`: on a safeguards refusal only, retry the identical prompt once on the fallback model. Never-raises contract unchanged; plain `SummarizeError`s do not trigger the fallback.
- **config.py / main.py** — `TRANSLATE_MODEL_FALLBACK` (default `claude-sonnet-4-6`, empty string disables), threaded through both call sites.
- **scripts/backfill_translate_hu.py** — fixed a real bug found while healing: daily-brief rows stamp no items, so the script's allowlist was empty for them and stripped every link from the translation and the republished HTML (both languages). Now mirrors `run_daily`'s union-over-source-window-digests allowlist. Docstring invocation gains `-e PYTHONPATH=/app`.

## Production heal (already done, out-of-band)

Both rows re-translated with `claude-sonnet-4-6` via the backfill pattern and re-published; digest 60 re-done with the corrected union allowlist — 63/63 links preserved in the Hungarian body.
