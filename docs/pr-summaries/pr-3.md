## Summary
- `prompts/digest.md` — fixed 3-section output contract, verbatim-URL linking rule, collector-failure banner, and a prompt-injection guard (item text is data, never instructions)
- `digest/summarize.py` — `claude -p` subprocess invocation (`ANTHROPIC_MODEL`, default `claude-opus-5`; configurable timeout); `SummarizeError` on non-zero exit / empty output / timeout, never leaking the prompt into errors
- `digest/emailer.py` — markdown→HTML with `&`/`<` pre-escaping (hostile raw HTML from scraped messages cannot reach the mail client), multipart plain+HTML over iCloud SMTP STARTTLS, best-effort archive to `ARCHIVE_DIR`
- `digest/state.py` — `digests.body_md` persisted before send: a crash or SMTP failure retries the send next run without re-summarizing (no double Opus calls)
- `digest/main.py` — `_deliver` pipeline: pending-send retry → empty-window no-op → summarize+send; collector failure always exits non-zero for the Loki alert
- 54 tests (summarizer subprocess mocked, SMTP faked, HTML-escaping regression, digest bookkeeping, delivery paths)
