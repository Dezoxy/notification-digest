## What

Makes the owner's five subreddits ingestible through the **existing** news collector, after live testing showed Reddit's anonymous `.json` is hard-blocked (403 regardless of pacing) while the public `.rss` feeds answer 200 — 3s spacing → 429 on 4/5 subs, **45s spacing → 200 on 4/5**.

- **Per-host pacing** (`_MIN_SECONDS_BETWEEN_SAME_HOST = 45`): local dict of monotonic readings per `collect()` call, no module state. Fires only on a *repeated* host, so the eight existing feeds never wait. Five subreddits add ~3 min to a run (600s timeout, ~2 min typical).
- **`chat_title` from the URL's `/r/<sub>` segment** instead of Reddit's publisher copy ("top scoring links : hungary"). Load-bearing: an RSS-ingested subreddit item now presents to the prompt *identically* to what PR #32's OAuth collector produces, so the standing `## Hungary` rule works on either path — and switching to OAuth later is two config values, not a prompt rewrite.
- **Prompt**: subreddit handling keys on `chat_title` starting with `r/` rather than the source value; the score/comments salience rule is conditional (RSS omits those figures, OAuth supplies them).

## Review fix

An autouse fixture neutralizes the pacing sleep in the RSS tests: two *pre-existing* same-host tests were sleeping 45 real seconds each, taking the suite from 6s → 94s. Autouse so a future same-host test can't silently reintroduce the tax.
