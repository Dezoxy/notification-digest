## Summary
`uv run python scripts/telegram_login.py` failed immediately with `ModuleNotFoundError: No module named 'digest'`. Running a script inside `scripts/` puts **scripts/** on `sys.path`, not the repo root, and `[tool.uv] package = false` means `digest` is never installed into the venv either — pytest only imports it because `pythonpath = ["."]` is set in pyproject. The script now inserts the repo root explicitly.

Found the first time the helper was actually run (during real Telegram setup) — it's the one file no test exercises, since it's interactive by nature.
