## Description
App half of §11.6 (site half: toom-edge #142, deployed). Generates the short "Background" primer that arc pages render for readers joining a story mid-thread.

**The scoping change that made §11.6 viable.** It was deferred partly because generated explainers "go stale as the arc evolves". These are BACKGROUND, not recaps — what the Strait of Hormuz is, who controls it, why markets react structurally. Background ages in years, so v1 generates once per arc and never regenerates. The arc's timeline right below already covers what happened.

- `digest/context.py` + `prompts/arc-context.md`: toolless call fed **only the arc's most recent label** — no brief text, so it can never become a replay channel for coverage (contrast §11.3's fencing). Prompt forbids headings, emphasis markers, and links, which matches the site's deliberate lack of a markdown renderer. Belt-and-braces: `enforce_link_allowlist(output, allowed_urls=())` defangs any link that slips through, since a primer has no legitimate citation.
- `INSUFFICIENT_CONTEXT` sentinel and every failure collapse to `None` → nothing stored, soft-fail like `translate_digest`, never blocks the daily.
- `user_version` 3→4: `arc_context(key PK, context_md, generated_at)`. Qualification: ≥2 appearances in 7 days, no primer yet, oldest-first, `LIMIT`-bounded.
- Trigger: **daily run only**, after that brief ships — bounds cost to ≤`CONTEXT_MAX_PER_RUN` (3) calls/day rather than per 3 hours. `CONTEXT_ENABLED` defaults **off**.
- Every publish carries the full current primer snapshot; the site upserts by `key` (`ON CONFLICT(key) DO UPDATE`, confirmed in toom-edge #142), so this is idempotent and self-healing rather than needing publish-confirmation tracking the 3-column schema doesn't have.

**Deliberately no tombstone** for a permanently-vague label: the `str | None` contract can't distinguish that from a transient CLI hiccup, and tombstoning both would permanently lose a good arc over one bad call. Worst case is bounded — ≤3 wasted calls/day, only while the story keeps recurring.
