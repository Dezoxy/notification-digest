# PR #53: Fix: daily briefs lost every citation link on every channel
[View PR](https://github.com/Dezoxy/notification-digest/pull/53) · @Dezoxy · merged 2026-08-09 · `a79712e` · `fix-daily-link-allowlist -> main` · +327/-4 across 5 files

## Description
**Bug** (owner-reported): citations in daily briefs render as bare superscripts with no links — site, email, and HU alike. Window digests unaffected.

**Root cause**: `deliver_channels` derived the allowlist via `get_digest_item_urls(digest_id)` for every kind, but a daily brief stamps no items (it consumes digests, not items), so the set was empty and `enforce_link_allowlist`/`_enforce_anchor_provenance` correctly defanged everything. Confirmed in production D1: dailies 68/77/86 have `body_md` links but zero anchors in `body_html`; 62–64 (created by the backfill script, which passes its own allowlist) are fine. Regression dates to the multi-channel cutover meeting the daily-brief feature.

**Fix**: kind-aware derivation — `get_daily_allowed_urls(conn, created_at)` unions the item URLs of window digests in `[created_at - DAILY_LOOKBACK_WINDOW, created_at)` in one query. Strict upper bound makes resends reproduce the original allowlist rather than a wider one. The lookback constant moves to state.py so synthesis and citation windows share one source of truth.

Both new tests were verified to FAIL against the unfixed `deliver.py` and pass with it. `uv run ruff check . && uv run pytest` green (670 passed).
