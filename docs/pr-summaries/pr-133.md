## Description
## A pin nothing was watching

```dockerfile
RUN npm install -g @anthropic-ai/claude-code@2.1.220
```

`config:recommended`'s dockerfile manager only reads `FROM` lines, so an
`npm install -g pkg@version` inside a `RUN` is invisible to it. There was no
`customManager` in this repo, so **nothing has ever opened a bump PR for this
pin**.

It sat at **2.1.220 while the rest of the fleet ran 2.1.251** — 31 patch
releases behind, on the one service that invokes the CLI several times a day.

The Dockerfile comment already said:

> bump both together, deliberately, not independently

No bot can read a comment. `Dezoxy/my-health-datas` has had the matching
`customManager` all along and drifted only 10 releases instead of 31 — that gap
is the evidence that the manager, not the comment, is what does the work.

## Changes

- add the `customManager` for the npm CLI pin, **byte-identical `matchStrings`
  to the one in `my-health-datas`** (verified programmatically, not by eye)
- bump the pin 2.1.220 → **2.1.251**, matching `claude_cli_version` in the
  homelab repo

Regex verified against the actual Dockerfile line:

```
depName=@anthropic-ai/claude-code  currentValue=2.1.251
```
