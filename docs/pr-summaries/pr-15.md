## What

Visual redesign of the HTML email. Everything lives in the `emailer.py` wrapper and its post-sanitize passes — **zero changes to the prompt contract or the model's output**.

- **Masthead**: "DIGEST · Thu, Jul 31 · 18:07" with an accent rule. The label is formatted in `main.py::_send_and_finalize` (Europe/Budapest, per convention: storage stays UTC, only render/email time converts) and threaded through `send_digest` → `render_html`.
- **"Needs attention" card**: the optional first section renders as an amber callout with an uppercase label instead of a plain `h2`.
- **TL;DR card**: labelled accent-tinted card; the `**TL;DR:**` prefix is stripped since the label replaces it.
- **Citation pills**: anchors whose entire text is superscript digits (`[¹](url)`) become small rounded pills — a real tap target on a phone instead of an ~8px superscript character.
- **Quiet footer**: the closing `*From N items…*` line gets muted, hairline-separated styling.
- **New palette** (indigo accent) with explicit dark-mode overrides for every new class, same inline-style + `<style>`-class belt-and-suspenders pattern as the existing banner/TL;DR passes.

## Security-relevant ordering

- `_style_citation_anchors` runs strictly **after** `_enforce_anchor_provenance`: a non-allowlisted anchor is unwrapped to bare text first, so a hostile citation can never be dressed up as a legitimate-looking pill. Covered by a pipeline-level test.
- `_wrap_needs_attention_section`'s lookahead stops at the next `<h2>` **or the TL;DR paragraph** — the prompt contract puts "Needs attention" directly above the TL;DR with no heading between, so without that branch the amber card would swallow the TL;DR card as a nested child. Covered by a sibling-structure test.
- All new passes follow the established pattern: constant module-owned markup injected around already-nh3-sanitized content, no re-parsing of attacker-controlled HTML, no-op when the target shape is absent.
