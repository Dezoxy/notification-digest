# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**. Please do not open a
public issue or pull request for a security problem.

This is a personal, single-owner project. Reports are handled on a best-effort
basis, with no response-time or fix-time commitment.

## Supported versions

Only the latest release is supported.

## Keep secrets out of public places

The repository is public. Do not put credentials, cookies, session strings or
personal data in issues, pull requests, comments or logs. If you find any in
the repository or its history, report it privately as above.
